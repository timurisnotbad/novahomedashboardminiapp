# Рекомендации после аудита (12.10.2026)

Пять релизов по отчёту `AUDIT-2026-10-12.md` выпущены: v74 безопасность, v75 данные, v76 скорость, v77 удобство,
v78 чистка. Ниже — что осталось и что стоит сделать дальше, по убыванию пользы.

## Нужно от владельца
1. **Резервные копии**: `data/nova.db`, `data/secrets.json`, `data/media/` — ежедневно копировать на другой диск
   или в облако (достаточно задачи планировщика Windows с `robocopy`). Сейчас потеря ноутбука = потеря всей переписки.
2. **Ключи Meta (WhatsApp Cloud / Instagram) и SMTP** — без них кнопки Email и каналы Instagram отключены (CRM честно
   это показывает). Когда появятся: `.env` → перезапуск.
3. **Токен RealtyCalendar** истекает: при «RC returned 0 bookings» в логе обновить `RC_TOKEN`/cookies. Стоит
   договориться с RC об API-ключе без срока.

  на телефоне заметно при 300+ чатах и длинных лентах с фото/видео.
- **Q13 (медиа)** — ретеншен каталога `data/media/`: файлы без ссылок из `inbox_messages` можно удалять через год;
  сейчас каталог только растёт.
- **Q6–Q10** — дальнейшее упрощение: убрать легаси чек-лист (`DEFAULT_CHECKLIST`/`parse_checklist`), разбить

  (делегирование), константы вместо магических чисел.
- **U9/U10/U14–U17/U19** — терминология (глоссарий: чат/гость/бронь/этап), мастер подключения каналов, пагинация

- **Мониторинг** — `/api/health` уже отдаёт версию и время синхронизации; подключить внешний пинг (UptimeRobot)

## Эксплуатация
- После обновления всегда: перезапуск сервера (`restart_all.bat`), проверка `/api/health` → `version` совпадает
  с архивом, страница «Каналы» зелёная.
- Раз в месяц смотреть «Интеграции → RealtyCalendar → последние записи» и журнал автосообщений: ошибки отправки
  видны там же, где и в задачах.
