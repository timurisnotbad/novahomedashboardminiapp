Nova Home CRM — расширение Chrome для сообщений Booking.com

1. Chrome → chrome://extensions → включить «Режим разработчика» → «Загрузить распакованное расширение» → выбрать эту папку (booking-ext).
2. Нажать на значок расширения → вписать адрес CRM и ключ (CRM → Каналы → Booking.com → «Установка и ключ») → Сохранить.
3. Открыть https://admin.booking.com → Сообщения и оставить вкладку открытой. Папку booking-ext не перемещать и не удалять.
4. Если сообщения не появляются в CRM: значок → «Снимок страницы» → прислать файл разработчику.


Обновление расширения
---------------------
После каждого обновления CRM (новый zip) папка booking-ext тоже обновляется.
Чтобы Chrome подхватил новую версию: chrome://extensions → на карточке
«Nova Home — Booking.com» нажмите ⟳ (Обновить) или выключите и включите
расширение. Версия видна в CRM → Каналы → Booking.com («Расширение на связи ·
версия 1.3»). Если там старая версия — Chrome ещё не перечитал папку.
