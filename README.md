# Nova Home Dashboard

Telegram-бот + Mini App для управления апартаментами Nova Home (Nest One, Ташкент):
брони из RealtyCalendar, уборки с отчётами «до/после», явка по live-локации,
штрафы и зарплата, сверка оплат из канала, список закупок, мониторинг цен Booking.com.

Бот: **@novahomedashboardbot** · Дашборд: **https://app.novahomedashboard.com**

## Установка обновления

1. Распаковать `nova-updateNN.zip` поверх папки `C:\NovaHome\novahomedashboard` (с заменой файлов).
2. Запустить `restart_all.bat` — он перезапустит сервер и бота (только процессы Nova).
3. Файл `.env` при обновлении не трогается. Все переменные описаны в `.env.example`.

Первый запуск на новом ПК:

```
install.bat                 ← ставит все библиотеки и сразу проверяет результат
playwright install chromium (только для вкладки «Цены»)
copy .env.example .env      → заполнить
restart_all.bat
```

Файлы для запуска и проверки:

| Файл | Что делает |
|---|---|
| `restart_all.bat` | перезапускает сервер и бота, освобождает порт 8000, проверяет, что оба живы |
| `start_bot.bat` / `start_server.bat` | запустить что-то одно; окно не закрывается, ошибка остаётся на экране |
| `install.bat` | установить/обновить библиотеки |
| `autostart.bat` | один раз: отключить сон компьютера и добавить Nova Home в автозагрузку Windows (после перезагрузки бот и сервер поднимутся сами) |
| `diagnose.bat` | самопроверка: библиотеки, `.env`, база, сервер, последние ошибки. Внизу окна — список найденных проблем, весь отчёт сохраняется в `logs\diagnose.txt` |
| `logs\bot.log`, `logs\bot-error.log`, `logs\server.log` | всё, что печатали окна, сохраняется сюда |

## Как пользуются горничные

| Действие | Что отправить боту (в личку или в тему «Уборки») |
|---|---|
| Пришла на работу | live-геолокация (Скрепка → Геопозиция → «Транслировать») с 09:00 до 14:00 |
| Начала уборку | кружок/фото + текст `до 103` — латиницей тоже: `do 103`, `do-103`, `do135`, `oldin 103`, `start 103` |
| Закончила уборку | кружок/фото + текст `103` (можно `после 103`, `posle-103`, `keyin 103`, `done 103`) |
| Ещё видео той же квартиры | просто кружок — бот привяжет к текущей уборке |
| Что-то нужно купить | `нужно 103 полотенца 2, шампунь` (узб. `103 ga sochiq 2 ta kerak`) |
| Посмотреть список закупок | `/нужно` |

В группе с темами бот читает отчёты **только в теме «Уборки»** (кружок в «Общении» — просто
кружок). Тему с таким названием бот привязывает сам при первом отчёте в ней; иначе владелец
отправляет в нужной теме `/topic уборки`. Вечерний план на завтра — одно сообщение в день:
при изменении броней ночью бот редактирует его, а не шлёт новое.

Обратная связь: когда всё в порядке, бот не пишет сообщение, а ставит реакцию на сообщение
человека: 👍 — принято (кружок ДО/ПОСЛЕ, приход вовремя), ✍ — записал в список (закупки,
«Поломки»). Текстом бот отвечает только когда что-то не так: опоздание, «после» без «до»,
квартиру убирает другая, номер не понят, вне зоны. Если в группе реакции отключены, бот
отвечает текстом, как раньше.

Правила: уборку закрывает та же горничная, что начала. Пока квартира у одной, другая не
может её «начать» или «закрыть». Забытый отчёт «после» закрывается сам через 8 часов и
помечается как незавершённый — квартира остаётся «без отчёта».

## Команды владельца

| Команда | Что делает |
|---|---|
| `/start` | кнопка дашборда (с ключом владельца — работает и на macOS) |
| `/today` | текстовая сводка дня |
| `/attendance` | кто отметился сегодня |
| `/staff`, `/staff_del <id>` | список сотрудников (пополняется сам), убрать уволенного |
| `/сброс 103` (`/reset`) | закрыть зависшую уборку; без номера — список открытых |
| `/нужно` (`/supplies`) | список закупок |
| `/цены` (`/prices`) | цены Booking.com на завтра; `/цены 12-14 сен` — на даты |
| `/topic уборки` \| `явка` \| `поломки` \| `общий` | внутри темы группы — привязать тему к типу сообщений; `/topic` без слова — показать, что привязано. Темы «Уборки» и «Поломки» бот привязывает сам по названию |
| `/chatid`, `/myid` | ID чата/темы, свой ID |

## Что бот делает сам

| Время | Событие |
|---|---|
| 08:00 | сводка дня владельцу |
| 09:00 | цены Booking.com на завтра владельцу |
| 10:00 | напоминание сотрудникам отправить локацию |
| 14:00 | перекличка в тему «Явка», неявка → автоштраф и запись в журнал |
| 18:00 | контроль уборок в тему «Уборки»; список закупок владельцу в личку |
| 22:00 | план на завтра в тему «Уборки»; при изменении броней ночью — обновлённый план |
| каждые 15 мин | синхронизация с RealtyCalendar, уведомления о новых/изменённых бронях владельцу |
| каждые 30 мин | автозакрытие уборок без отчёта «после» старше 8 часов |
| 01:00–08:00 | все сообщения без звука |
| постоянно | читает тему «Поломки»: строки «купить…» / «нет…» → Контроль → Закупки, остальное («починить…») → Контроль → Задачи; квартира берётся из строки («В-071», «около 066»); подтверждение — реакция ✍ на сообщении, без ответов в чат; дописанные при редактировании строки добавляются |

## Уведомления, если что-то упало

Два слоя, оба пишут владельцу в личку:

| Слой | Кто следит | Когда придёт сообщение |
|---|---|---|
| На компьютере | сервер следит за ботом (отметка `logs\bot-heartbeat.txt` раз в минуту), бот следит за сервером (`/api/health`) | «🔴 Бот не отвечает с 03:12» через 3 мин тишины; «🔴 Сервер не отвечает» через 3 мин; «🟢 снова в сети» при восстановлении. После перерыва дольше 5 мин бот сам пишет «🟢 Бот снова в сети, не работал с …» |
| Снаружи (healthchecks.io, бесплатно) | внешний сервис ждёт «я жив» от бота и сервера каждую минуту | если компьютер выключен, уснул или нет интернета, изнутри никто написать не может; healthchecks.io пришлёт в Telegram «check is down» через заданный запас времени |

Настройка внешнего слоя (один раз, 5 минут):
1. Зарегистрироваться на https://healthchecks.io (бесплатный план, до 20 проверок).
2. Integrations → Telegram → «Add integration» → откроется бот @HealthchecksBot, нажать Start. Уведомления пойдут в личку.
3. Add Check → имя «Nova Bot», Period 2 minutes, Grace 5 minutes → скопировать ping-ссылку `https://hc-ping.com/…` в `.env` как `HEARTBEAT_URL_BOT=`.
4. Ещё одна проверка «Nova Server» → `HEARTBEAT_URL_SERVER=`.
5. `restart_all.bat`. Через минуту обе проверки на сайте станут зелёными.

## Дашборд

Сотрудники видят: Сегодня, Завтра, Уборки (кто убирает и сколько заняло), Неделя, Задачи.
Владелец дополнительно: Гости, Касса (Баланс / Штрафы / Зарплата), Цены, Оплаты, Контроль
(Явка / Уборки / Закупки / Задачи — у владельца задачи живут внутри «Контроля»).
Наблюдатели оплат (PAY_VIEWERS) видят только «Оплаты».

Доступ к данным есть только у тех, кто открыл дашборд из бота; по прямой ссылке
показывается подсказка открыть через бота.

## CRM для офиса

Полноценная CRM в браузере: **https://app.novahomedashboard.com/crm/** — вход по
email и паролю, работает на компьютере и телефоне. Ничего дополнительно ставить не
нужно: это тот же сервер, что и дашборд.

**Первый вход:** открыть `/crm/` — страница предложит создать администратора (имя,
email, пароль). Дальше администратор добавляет сотрудников в «Пользователи».

| Раздел | Что там |
|---|---|
| Главная | заезды/выезды сегодня, непрочитанные, мои задачи, воронка, последние чаты |
| Сообщения | те же «Чаты» WhatsApp — вся переписка команды, быстрые команды через `/` |
| Сделки | канбан по этапам воронки: перетащить карточку = сменить этап. Клиент, объект, даты, сумма, ответственный |
| Клиенты | карточки с телефоном, источником, своими полями; брони, сделки, задачи и чат клиента в одном месте. «Подтянуть из броней и чатов» создаёт карточки по номерам |
| Задачи | Мои / Все, Открытые / Выполненные, срок и исполнитель. Задачи «Заезд» и «Выезд» создаются сами на день брони (выключается в «Интеграциях») |
| Брони | из RealtyCalendar: «День» — заезды и выезды, «Шахматка» — 30 дней по объектам. Кнопка «+ Сделка» заводит сделку из брони |
| Каналы | состояние WhatsApp и QR-код для привязки |
| Интеграции | RealtyCalendar (синхронизировать сейчас), Google-таблица, Telegram, Healthchecks |
| Быстрые команды | `/wifi`, `/оплата`… с переменными `{имя}` `{объект}` `{заезд}` `{выезд}` — подставляются из брони гостя |
| Поля карточек | свои поля клиента: текст, число, дата, список, галочка |
| Воронки | этапы сделок; этап «успех»/«отказ» закрывает сделку |
| Пользователи | администраторы и менеджеры, блокировка (заблокированный сразу теряет доступ) |
| Выручка | по данным RealtyCalendar: месяц по каналам (Booking/Airbnb/прямые), по объектам, загрузка, средняя цена ночи, 12 месяцев. Обновляется каждой синхронизацией |
| Автосообщения | правила, которые владелец настраивает сам: событие (за N дней до заезда, в день заезда/выезда, через N дней после, первое сообщение, нерабочее время), время, канал, текст с переменными, фильтр по источнику. «Что отправится сейчас» показывает список без отправки; журнал отправок |

**Бронь — центр всего.** Клик по брони (в «Дне» или в «Шахматке») открывает карточку: гость, история
(визитов, ночей, сумма, квартиры), особенности гостя (комментарий — виден и в чате), чаты из любых
каналов — найденные по номеру и закреплённые вручную (📌 — например, Instagram-чат без телефона),
отправка сообщения выбранному чату с шаблоном, сделка, журнал автосообщений.

**Уведомления в CRM:** новое входящее из любого канала — звук и всплывающая плашка (клик открывает
чат); если вкладка свёрнута — системное уведомление браузера (разрешить внизу меню).

**Excel:** «Клиенты» → «⬇ Excel» — все клиенты с визитами, ночами, суммами, квартирами, комментариями,
своими полями и каналами связи; второй лист — все брони.

Менеджер видит всё, кроме настроек (пользователи, воронки, поля, отключение WhatsApp).
Все данные CRM — в той же базе `nova_dashboard.db`.

## Чаты WhatsApp (свой Wazzup)

Общий WhatsApp рабочего номера для всей команды: гости пишут как обычно, а отвечать
может любой сотрудник — с телефона в Telegram или с компьютера в браузере. Каждый
ответ подписан именем того, кто ответил.

**Первый запуск (один раз):**

1. Установить **Node.js LTS** с https://nodejs.org (галочки по умолчанию).
2. Запустить `install.bat` — он поставит и библиотеки моста WhatsApp (`wa-bridge`).
3. `restart_all.bat` — откроется третье окно **«Nova WhatsApp»**, его не закрывать.
4. Владелец: написать боту `/chats` → «Открыть чаты» → вверху кнопка **«Нужен QR»**.
5. На рабочем телефоне: WhatsApp → Настройки → **Связанные устройства** → Привязка
   устройства → навести камеру на код. Через несколько секунд кнопка станет
   зелёной «WhatsApp», подтянутся переписки за последние 30 дней.

Телефон продолжает работать как обычно: сообщения видны и там, и в «Чатах».
Если Wazzup подключён к этому же номеру, его можно отключить (Связанные устройства).

**Как пользуются сотрудники:**

| Действие | Как |
|---|---|
| Открыть чаты на телефоне | `/chats` → «💬 Открыть чаты» или кнопка 💬 вверху дашборда |
| Открыть на компьютере | `/chats` → «🖥 Открыть в браузере» — личная ссылка, сохранить в закладки |
| Ответить | выбрать чат слева, написать внизу, Enter — отправить (Shift+Enter — новая строка) |
| Ответить на конкретное сообщение | навести на сообщение → стрелка, или двойной клик |
| Фото / файл | скрепка или вставить картинку Ctrl+V (до 30 МБ) |
| Шаблоны («инструкция заезда», «реквизиты») | кнопка `/` рядом со скрепкой; там же добавить новый |
| Написать гостю первым | «+» рядом с поиском, номер с кодом страны |
| Взять чат на себя | список «👤» в шапке чата; фильтр «Мои». Кто ответил первым — тот и ответственный |
| Ответить прямо из Telegram | ответить (reply) на уведомление «💬 WhatsApp …» — текст уйдёт гостю |

В шапке чата и в списке видно апартамент и даты брони гостя — бот находит его в
RealtyCalendar по номеру телефона. Поиск ищет по имени, номеру и апартаменту.

**Уведомления** о новых сообщениях по умолчанию приходят владельцам в личку.
Чтобы получала вся команда: `INBOX_NOTIFY_CHAT_IDS=<ID рабочей группы>` в `.env`;
в группе с темами создайте тему «Чаты» и отправьте в ней `/topic чаты`.

**Каналы.** Кроме WhatsApp по QR в «Чаты» (и в CRM → Сообщения) попадают — настраивается в CRM → «Каналы»,
там же пошаговые инструкции:

| Канал | Что нужно | Особенности |
|---|---|---|
| WhatsApp по QR | Node.js, окно «Nova WhatsApp» | бесплатно, как WhatsApp Web; неофициально |
| WhatsApp Cloud API | приложение Meta: `WA_CLOUD_TOKEN`, `WA_CLOUD_PHONE_ID`, вебхук | официально, номер не заблокируют; 1000 диалогов/мес бесплатно; писать первым или спустя 24 ч — только шаблоном |
| Instagram Direct | Facebook-страница + бизнес-Instagram: `IG_PAGE_TOKEN`, вебхук | ответы в течение 24 ч после сообщения гостя |
| Telegram — аккаунт компании | `TG_API_ID`, `TG_API_HASH` с my.telegram.org, вход по номеру в CRM | личные чаты аккаунта видны всей команде |
| Telegram-бот для гостей | `TG_GUEST_BOT_TOKEN` от @BotFather | гость пишет боту первым |

Все каналы идут в одну «трубу»: чат → карточка клиента в CRM (по номеру телефона или по
аккаунту) → уведомление в Telegram → ответ из CRM, из чатов в Telegram или reply-ем на уведомление.

**Доступ:** владельцы и все сотрудники из `/staff`. Ограничить — `INBOX_USERS=@anna, 123456`.
Уволенный сотрудник (`/staff_del`) сразу теряет доступ, его личная ссылка перестаёт работать.

**Важно:** подключение идёт тем же способом, что WhatsApp Web и Wazzup (неофициально,
через «Связанные устройства»). Не делайте массовых рассылок незнакомым номерам —
WhatsApp за это блокирует номера. Обычная переписка с гостями безопасна.

Данные: сообщения — в `nova_dashboard.db`, фото и файлы — в папке `data\inbox_media`,
сессия WhatsApp — `wa-bridge\auth` (удалить папку = отвязать телефон).

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| Красная плашка «Сервер не обновлён» или «Не удалось загрузить данные» на всех устройствах после обновления | Старый процесс сервера пережил перезапуск и раздаёт новые файлы старым кодом | Закрыть окна «Nova Backend» и «Nova Bot», запустить `restart_all.bat`; он освобождает порт 8000 и печатает версию сервера |
| Проверить версию сервера вручную | | Открыть `https://app.novahomedashboard.com/api/health` — поле `version` должно совпадать с номером обновления |
| «Нет доступа. Откройте через кнопку в боте» | Дашборд открыт по прямой ссылке | Открыть через «📊 Дашборд» в боте |
| На Mac режим сотрудника | Клиент не передал подпись, `OWNER_KEY` пуст | Добавить в `.env` строку `OWNER_KEY=длинный-секрет`, перезапустить, нажать `/start` |
| В «Кассе» нет новых квартир | Баланс приходит из Google-таблицы, лист «Счета» | Добавить строки новых квартир в лист «Счета»; приложение показывает то, что отдаёт таблица |
| Бот молчит на кружок в группе | Кружок не в теме «Уборки» | Отправлять в тему «Уборки» или в личку боту |
| Открыл дашборд, а вёрстка старая (нет процентов по дням на «Неделе») | Telegram закэшировал старые файлы | С версии 26 файлы подписаны номером версии; закрыть мини-приложение свайпом вниз и открыть заново |
| В «Кассе» блок «⚠️ Нет в ответе таблицы: …» | Скрипт таблицы (Apps Script) не отдаёт строки этих квартир | Добавить строки в лист «Счета» и проверить в скрипте список/фильтр квартир |
| Сервер не стартует после правки `.env` | Опечатка в числе или комментарий после значения | С версии 26 комментарии и кавычки в `.env` допустимы, опечатки в числах заменяются значением по умолчанию; смотрите окно «Nova Backend» |
| Окно бота открывается и сразу закрывается | Не хватает библиотеки, занят токен или ошибка в `.env` | Запустить `start_bot.bat` — окно останется открытым с текстом ошибки; та же ошибка в `logs\bot-error.log`. Затем `diagnose.bat` и скриншот |
| Бот работает, но перекличка 14:00 и контроль 18:00 не приходят | Не установлен `pytz` — без него у бота нет планировщика | Запустить `install.bat`; проверить в `diagnose.bat` пункт «РАСПИСАНИЕ БОТА» |
| Meta пишет «не удалось проверить URL вебхука» | Неверный verify token или сервер недоступен снаружи | `META_VERIFY_TOKEN` в `.env` и в настройках вебхука должны совпадать; адрес `https://…/api/inbox/meta/webhook` должен открываться из интернета |
| Cloud API: «Прошло больше 24 часов…» | Правило Meta | Отправить утверждённый шаблон из Meta Business Manager или дождаться сообщения гостя |
| Telegram-аккаунт: «не отвечает» | С компьютера нет доступа к серверам Telegram | Проверить интернет/VPN; CRM пробует подключиться каждую минуту |
| «Мост выключен» в «Чатах» | Окно «Nova WhatsApp» закрыто или нет Node.js | `restart_all.bat`; если окна нет — установить Node.js LTS и `install.bat` |
| «Нужен QR» в «Чатах» | Телефон отвязал устройство | Владелец: «Нужен QR» → отсканировать заново (бот пишет владельцу, когда связь потеряна) |
| Сообщение с красным «Не отправлено» | WhatsApp был не подключён в этот момент | Нажать «повторить» под сообщением |
| «Бот уже запущен в другом окне» | Открыто два окна «Nova Bot» | Закрыть лишнее или запустить `restart_all.bat` |
| Бот «сам» пропадает раз в несколько дней, в логах ошибок нет | Чаще всего компьютер: ночная перезагрузка Windows Update, сон, отключение света, закрытая сессия удалённого рабочего стола | Запустить `diagnose.bat` — раздел 8 показывает отметку жизни бота, паузы в логах и события Windows (перезагрузка/сон) за 7 дней. Один раз запустить `autostart.bat`: отключает сон и добавляет автозапуск после входа в Windows; затем настроить автовход (`netplwiz`). С версии 33 окна `Nova Bot`/`Nova Backend` сами перезапускают процесс, если он завершился, а бот перезапускается, если опрос Telegram остановился |

```
bot.py                  Telegram-бот (python-telegram-bot v20)
backend/main.py         FastAPI, раздаёт frontend/ и /api
backend/database.py     SQLite (nova_dashboard.db), схема и запросы
backend/services.py     расчёт экранов (сегодня/завтра/уборки/занятость)
backend/rc_sync.py      RealtyCalendar
backend/attendance.py   геозона и опоздания
backend/supplies.py     парсер заявок на закупки
backend/pay_parse.py    парсер постов канала оплат
backend/booking_prices.py  Booking.com (Playwright)
backend/routers/        API: dashboard, cleaning, tasks, payroll, penalties, payrecon, control, prices…
frontend/               Mini App (vanilla JS), js/screens/* — экраны
frontend/inbox/         «Чаты» WhatsApp (страница для телефона и компьютера)
frontend/crm/           CRM для офиса (/crm/): сделки, клиенты, задачи, брони, настройки
backend/crm.py          CRM: пользователи и сессии, сделки, воронки, клиенты, задачи
backend/meta_api.py     WhatsApp Cloud API + Instagram Direct (вебхук Meta, Graph API)
backend/tg_channels.py  Telegram как канал: аккаунт компании (Telethon) и бот для гостей
backend/inbox.py        «Чаты»: хранение переписки, доступ, уведомления
wa-bridge/              связь с WhatsApp (Node.js, Baileys, вход по QR)
restart_all.bat         перезапуск сервера, бота и моста WhatsApp
```
