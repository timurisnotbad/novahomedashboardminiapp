# Nova Home Dashboard

Telegram-бот + Mini App для управления апартаментами Nova Home (Nest One, Ташкент):
брони из RealtyCalendar, уборки с отчётами «до/после», явка по live-локации,
штрафы и зарплата, сверка оплат из канала, список закупок, мониторинг цен Booking.com.

Бот: **@novahomedashboardbot** · Дашборд: **https://app.novahomedashboard.com**

## Установка обновления

1. Распаковать `nova-updateNN.zip` поверх папки `C:\NovaHome\novahomedashboard` (с заменой файлов).
2. Запустить `restart_all.bat` — он перезапустит сервер и бота (только процессы Nova).
3. Файл `.env` при обновлении не трогается. Все переменные описаны в `.env.example`.

Первый запуск на новом ПК:

```
pip install -r backend\requirements.txt
pip install playwright && playwright install chromium   (только для вкладки «Цены»)
copy .env.example .env   → заполнить
restart_all.bat
```

## Как пользуются горничные

| Действие | Что отправить боту (в личку или в тему «Уборки») |
|---|---|
| Пришла на работу | live-геолокация (Скрепка → Геопозиция → «Транслировать») с 09:00 до 14:00 |
| Начала уборку | кружок/фото + текст `до 103` (узб. `oldin 103`) |
| Закончила уборку | кружок/фото + текст `103` |
| Ещё видео той же квартиры | просто кружок — бот привяжет к текущей уборке |
| Что-то нужно купить | `нужно 103 полотенца 2, шампунь` (узб. `103 ga sochiq 2 ta kerak`) |
| Посмотреть список закупок | `/нужно` |

Правила: уборку закрывает та же горничная, что начала. Пока квартира у одной, другая не
может её «начать» или «закрыть». Забытый отчёт «после» закрывается сам через 8 часов и
помечается как незавершённый — квартира остаётся «без отчёта».

## Команды владельца

| Команда | Что делает |
|---|---|
| `/start` | кнопка дашборда (с ключом владельца — работает и на macOS) |
| `/today` | текстовая сводка дня |
| `/attendance` | кто отметился сегодня |
| `/staff`, `/staff_del <id>` | список сотрудников (пополняется сам), убрать уволенного |
| `/сброс 103` (`/reset`) | закрыть зависшую уборку; без номера — список открытых |
| `/нужно` (`/supplies`) | список закупок |
| `/цены` (`/prices`) | цены Booking.com на завтра; `/цены 12-14 сен` — на даты |
| `/topic уборки` \| `явка` \| `общий` | внутри темы группы — привязать тему к типу сообщений |
| `/chatid`, `/myid` | ID чата/темы, свой ID |

## Что бот делает сам

| Время | Событие |
|---|---|
| 08:00 | сводка дня владельцу |
| 09:00 | цены Booking.com на завтра владельцу |
| 10:00 | напоминание сотрудникам отправить локацию |
| 14:00 | перекличка в тему «Явка», неявка → автоштраф и запись в журнал |
| 18:00 | контроль уборок в тему «Уборки»; список закупок владельцу в личку |
| 22:00 | план на завтра в тему «Уборки»; при изменении броней ночью — обновлённый план |
| каждые 15 мин | синхронизация с RealtyCalendar, уведомления о новых/изменённых бронях владельцу |
| каждые 30 мин | автозакрытие уборок без отчёта «после» старше 8 часов |
| 01:00–08:00 | все сообщения без звука |

## Дашборд

Сотрудники видят: Сегодня, Завтра, Уборки (кто убирает и сколько заняло), Неделя, Задачи.
Владелец дополнительно: Гости, Касса (Баланс / Штрафы / Зарплата), Цены, Оплаты, Контроль
(Явка / Уборки / Закупки). Наблюдатели оплат (PAY_VIEWERS) видят только «Оплаты».

Доступ к данным есть только у тех, кто открыл дашборд из бота; по прямой ссылке
показывается подсказка открыть через бота.

## Если что-то не работает

| Симптом | Причина | Что делать |
|---|---|---|
| Красная плашка «Сервер не обновлён» или «Не удалось загрузить данные» на всех устройствах после обновления | Старый процесс сервера пережил перезапуск и раздаёт новые файлы старым кодом | Закрыть окна «Nova Backend» и «Nova Bot», запустить `restart_all.bat`; он освобождает порт 8000 и печатает версию сервера |
| Проверить версию сервера вручную | | Открыть `https://app.novahomedashboard.com/api/health` — поле `version` должно совпадать с номером обновления |
| «Нет доступа. Откройте через кнопку в боте» | Дашборд открыт по прямой ссылке | Открыть через «📊 Дашборд» в боте |
| На Mac режим сотрудника | Клиент не передал подпись, `OWNER_KEY` пуст | Добавить в `.env` строку `OWNER_KEY=длинный-секрет`, перезапустить, нажать `/start` |
| В «Кассе» нет новых квартир | Баланс приходит из Google-таблицы, лист «Счета» | Добавить строки новых квартир в лист «Счета»; приложение показывает то, что отдаёт таблица |
| Бот молчит на кружок в группе | Кружок не в теме «Уборки» | Отправлять в тему «Уборки» или в личку боту |

## Структура

```
bot.py                  Telegram-бот (python-telegram-bot v20)
backend/main.py         FastAPI, раздаёт frontend/ и /api
backend/database.py     SQLite (nova_dashboard.db), схема и запросы
backend/services.py     расчёт экранов (сегодня/завтра/уборки/занятость)
backend/rc_sync.py      RealtyCalendar
backend/attendance.py   геозона и опоздания
backend/supplies.py     парсер заявок на закупки
backend/pay_parse.py    парсер постов канала оплат
backend/booking_prices.py  Booking.com (Playwright)
backend/routers/        API: dashboard, cleaning, tasks, payroll, penalties, payrecon, control, prices…
frontend/               Mini App (vanilla JS), js/screens/* — экраны
restart_all.bat         перезапуск сервера и бота
```

Резервная копия базы — файл `nova_dashboard.db` в папке проекта; копируйте его перед
большими обновлениями.
